2. HOW THE PROJECT WORKS (ARCHITECTURE)
========================================================================
Stack: React 19 + Vite 8 + React Router 7 (SPA).
- index.html            -> HTML entry point that loads the React app
- vite.config.js        -> Vite build config
- src\main.jsx          -> React bootstrap (mounts the app)
- src\App.jsx           -> App shell + routes
- src\pages\            -> Route pages: Home, About, Projects, CaseStudy, Contact
- src\components\       -> Reusable UI: Layout, ProjectCard, Cat, Background
- src\data\             -> Static data: projects.js, cats.js
- src\theme.js / themeColor.js / adaptiveAccent.js -> theming
- public\               -> Static assets served as-is (images, resume.pdf, sw.js, favicon)
- public\assets\cats\   -> Cat images (cookie.jpg, jeeru.jpg, masala.jpg)
- public\images\        -> Person images (imran, priya, rohit, sunita webp)
- .github\workflows\deploy.yml -> GitHub Actions that deploy to GitHub Pages
- DESIGN_SYSTEM.md      -> Design system docs
- package.json          -> Scripts: dev, build, lint, preview

GitHub Pages URL site: it is the artsbyankit.github.io repo, so the live site
is normally https://artsbyankit.github.io/

6. NOTES & TIPS FOR THE LOCAL AI
========================================================================
- This is an OFFICIAL Google Gemma 4 E4B + custom setup; keep code style
  consistent with existing .jsx components.
- Do not modify package.json version ranges unless necessary.
- If the dev server port 5173 is busy, Vite auto-picks another port;
  read the running window output for the actual URL.
- The GitHub Actions deploy workflow expects the repo to live at
  F:\portfolio\ and deploys the /dist build to GitHub Pages.
- LM Studio must be running with the server enabled for any opencode
  session that uses local models. If opencode seems slow, the fallback is
  to switch back to a cloud model via /models in the opencode TUI.
